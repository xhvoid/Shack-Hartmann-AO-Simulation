Fixed configuration & scope
Configurationdet_ccd_42m_r3band_derived@1; 500 steps; root seed 1; realization 0. Full configuration and identity are saved with the recording.
Atmosphere & guide sourcer₀ = 0.13 m at 500 nm; L₀ = 25 m. The declared WFS flux is 10⁵ detected electrons per fully illuminated subaperture per 2 ms frame. It is a synthetic guide-source setting, independent of the archival binary.
Pupil & detector assumptionsCircular 42 m pupil with 28% central obscuration; no segment gaps or spiders. The camera is an assumed synthetic CCD preset, not a measured ESO detector.
Numerical setup1008 × 1008 pupil; 84 × 84 lenslets; 85 × 85 DM grid; native ten-layer atmosphere; synthetic CCD noise enabled. Integrator gain 0.3; leak 0; two queued latency frames, first visible response at step 3; 100 μm finite OPD stroke.
What is recorded500 full-resolution atmosphere/residual map pairs and metrics; 126 full-grid PSF pairs for replay. The 400-frame mean uses every sample in [100, 500), not just display snapshots.
What is establishedOne reproducible numerical trajectory and a paired image-formation demonstration. It does not establish parameter robustness, long-run stationarity, hardware performance or instrument validation.
Geometry context42 m refers to the historical E-ELT study scale. The current ESO ELT is 39 m. This demonstration is not an ELT instrument model. Historical DRM · Current ELT
Relationship to the 2 m replayThe same recording and synchronization principles are used. Different wavelengths and system configurations mean these viewers are not a controlled aperture-only comparison.
Scientific photograph & image processing

NASA/ESA Hubble Space Telescope, ACS/HRC program 9451. Calibrated product j6kt02020_drz.fits, F775W, 2002-10-21, 440 s total exposure, 0.025″ pixels. Retrieved from MAST (STScI). Original FITS · MAST data use.

A fixed 161 × 161 pixel crop is background-subtracted using an outer annulus. All four input exposure quality arrays have zero saturation flags in the 31 × 31 pixel region around the binary. Signed pixel values are retained and resampled by exact pixel-area overlap to the simulation’s angular sampling. The total template flux is normalized once. There is no deconvolution, component replacement, artificial change in binary separation, per-frame brightness adjustment or added science-camera noise.

The simulation applies the same on-axis PSF across this compact source. Full linear convolution uses zero extension and the recorded zero-angle kernel origin. The displayed field is cropped afterwards. All binary panels share one fixed asinh display mapping; negative values are clipped only for display. HST diffraction, sampling and observational noise remain in the template.

Source image axes are preserved. The displayed orientation is not presented as north-up or as a physical alignment with the simulated pupil.

The run stores its complete configuration, seed, frozen producer sources, numerical-core identity, package versions and output hashes. Pinned package versions match the project lock; the shared environment contains additional packages, disclosed in the plan. An eight-step fixture confirmed unchanged loop history with the recorder enabled; no second full 42 m control trajectory was run.

Displayed map and PSF files are derived from the saved numerical arrays. No display pixels feed back into scientific metrics. Each fetched replay asset is checked against its SHA-256 manifest before it is shown.
