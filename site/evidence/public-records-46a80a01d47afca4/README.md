# Public reading copies

These two JSON files are edited copies, not the original evidence files.
Only `/argv/0` in the 42 m record and `/source_identity/branch` in the
noise-law record have been shortened or replaced. Each copy also adds a
`_public_copy` block explaining that change. All scientific values and the
remaining original provenance fields are unchanged.

`sources.json` records the original SHA-256, size and immutable source link.
The unedited records remain in the dataset and Git history. Use those
originals when checking an original producer hash. The manifest here binds
the new copies to their own hashes; it does not reuse the original hashes.
