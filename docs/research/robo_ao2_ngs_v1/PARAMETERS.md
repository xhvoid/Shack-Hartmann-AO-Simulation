# The 2.2 m natural-guide-star model

The model follows the internal MEMS mirror and natural-guide-star mode of Robo-AO-2 on the UH 2.2 m telescope. It uses 16 lenslets across the pupil, a 17-across actuator grid and 197 illuminated actuator centres. The detector model uses an EMCCD proxy. The projected actuator pitch is 0.1375 m.

The parameter ledger identifies the hardware specifications, values taken from published simulations and assumptions made for this model. Both versions use the same optical and camera settings.
